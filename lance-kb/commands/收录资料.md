# 收录资料

用户想把资料放进本地知识库时：

1. 先 `kb_stats` 看库里已有什么（有没有同一个目录已经收过、用的什么嵌入后端）。
2. 确认要收的范围：
   - 给了明确路径 → `kb_add(paths=[路径], tags="...")`
   - 只说「我的笔记/文档」→ 先问清楚目录，别猜（猜错会把无关文件灌进库）
   - 是一段结论或纪要 → `kb_add(name="标题", text="正文", tags="...")`
3. 入库后回报：新增 / 更新 / 跳过（内容没变）/ 失败各多少，当前总文档数与总字数。
   失败项要说明原因（缺少 pypdf 读不了 PDF、二进制文件被跳过等），不要含混过去。
4. 如果用户要的是「以后持续保鲜」→ 告诉他之后用 `kb_sync`，或直接建成定时任务
   （「每天早上 9 点同步本地知识库」）。

不要用 `force=true` 除非用户明确要求重建；增量跳过是有意的设计。
